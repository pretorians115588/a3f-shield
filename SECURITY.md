# Security policy

This repository contains experimental cryptographic research software. It has
not received an independent cryptographic audit and must not protect the only
copy of sensitive or irreplaceable data.

Do not open a public issue containing keys, ciphertexts, personal data, or an
unfixed vulnerability. Send a private report to the repository maintainer
after the repository owner adds the intended contact address here.

Supported security fixes are limited to the current development branch until a
first public release is explicitly declared.
